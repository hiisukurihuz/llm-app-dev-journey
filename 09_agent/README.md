# 09 · 智能体（Agent）

> 状态：⏳ 未开始 ｜ 前置：07_langchain

## 这个模块解决什么问题

大模型只会"说"，Agent 让它"做"：给它工具、让它自己决定调用顺序、失败能重试、
做完能自查。这个模块是第二阶段的重点，也是招聘 JD 里出现频率最高的词。

## 知识点（计划）

- [ ] Agent 与"带工具的 Prompt"的本质差别（循环 + 自主决策）
- [ ] Tools：工具定义、参数 schema、返回值设计、错误返回
- [ ] ReAct（推理 + 行动交替）
- [ ] Plan-and-Execute（先规划再执行，适合长任务）
- [ ] Self-Ask / Chain-of-Thought / Structured Chat 三种范式
- [ ] 记忆：短期（消息）、长期（向量库）、摘要
- [ ] 评估：任务成功率、工具调用正确率、平均轮数、成本
- [ ] 优化：提示词层 / 工具层 / 流程层三层优化
- [ ] 失败处理：工具报错重试、死循环截断、兜底回复

## 验收标准（能脱稿讲清）

1. ReAct 的一次完整循环包含哪几步？什么时候停？
2. 工具描述写不好会引发什么后果（选错工具、参数编造）。
3. 工具调用失败/超时，你的 Agent 会怎么处理？怎么防止死循环。
4. 怎么评估一个 Agent 变好了？指标怎么定义、测试集怎么造。
5. Plan-and-Execute 和 ReAct 各自适合什么任务。
6. 你在 `04_tools` 里怎么保证模型不会执行危险操作（白名单/人工确认）。
