## 验收标准（能脱稿讲清）

1. 列表和元组在内存与使用场景上的区别；为什么字典查找是 O(1)。
2. 默认参数为什么不能用可变对象（`def f(x, lst=[])` 的坑）。
3. `is` 和 `==` 的区别；小整数缓存、字符串驻留各是什么。
4. 闭包为什么能"记住"外层变量；装饰器如何不改原函数实现增强。
5. 继承 + 多态在房产项目里具体体现在哪一层。
6. 生成器相比 `readlines()` 省的是什么资源，为什么面试必问。
7. 房产项目的三层如何解耦：换掉存储层（CSV → MySQL）要改几个文件？
