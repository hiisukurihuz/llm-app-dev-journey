## 写文档的原则

1. **先写给自己**：三个月后你还要能看懂为什么当时这么写。
2. **带数字**：`TopK 从 3 调到 5，Recall@3 从 72% 到 89%` 比"效果变好了"有用一百倍。
3. **写失败**：报错、走错的弯路、被推翻的方案，是最能体现思考过程的部分。
