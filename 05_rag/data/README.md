# data/ · 示例文档

这个目录放 RAG 演示要用的原始文档（PDF / Markdown / TXT）。

## 为什么不直接附带 PDF

- **版权**：示例材料多为第三方发布的文档，不适合随开源仓库分发；
- **体积**：解析后的向量库可重建，但原始 PDF 提交后无法从历史里移除，只会越滚越大。

## 怎么准备

任选一种放进本目录，代码会按文件名读取：

1. 找一份自己有权使用的 PDF（产品说明书、公开技术白皮书都行）；
2. 或者自己写一份 20 页左右的 Markdown 当测试语料；
3. 追求效果时再换更长的真实文档。

## 约定

- 原始文档**不进 Git**（根 `.gitignore` 已排除 `*.pdf` / `*.docx`）；
- 向量库持久化目录同样不进 Git，跑脚本时自动重建。

跑之前确认一下：

```powershell
dir 05_rag\data
```
