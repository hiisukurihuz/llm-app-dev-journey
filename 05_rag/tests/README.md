# tests/ · 评测与测试

RAG 系统"感觉还行"不算完成，要有可重复的数字。这个目录放两类东西：

## 1. 单元测试（pytest）

先写最小的三个，覆盖最容易悄悄坏掉的地方：

| 测试 | 断言什么 | 防的是什么 |
|---|---|---|
| 分块边界 | 句子不被截断、相邻块重叠长度符合预期 | 改分块参数后悄悄切断语义 |
| 检索命中 | 问"年假多少天"能召回含答案的块 | 换 Embedding 模型后召回变差 |
| 引用存在 | 回答里引用的片段确实来自检索结果 | 模型编造原文里没有的内容 |

## 2. 评测集（evals）

- `eval_set.jsonl`：30-50 条 `{question, ground_truth, source}` 标准问答
- `run_eval.py`：批量跑一遍，输出召回率 / 忠实度 / 平均耗时

改完 prompt 或分块策略后重跑一次，用数字对比，而不是靠印象判断"好像变好了"。

```powershell
pytest 05_rag\tests -q
```
