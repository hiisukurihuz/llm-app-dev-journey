# 11 · 大模型微调

> 状态：⏳ 未开始 ｜ 前置：04_llm_basics

## 这个模块解决什么问题

RAG 解决"模型不知道"，微调解决"模型不会按你的方式做"。这个模块不追求训出好模型，
只追求走通一次完整流程，并且**能用数字说清微调前后差多少**。

## 知识点（计划）

- [ ] 微调发展史：全参微调 → 参数高效微调（PEFT）
- [ ] SFT（有监督微调）到底在做什么
- [ ] LoRA / QLoRA 原理：只训练低秩矩阵，为什么省显存
- [ ] 数据准备：指令-回答对怎么构造、多少条起步、质量比数量重要
- [ ] 训练参数：学习率、batch、epoch、显存不够怎么办
- [ ] 评估：微调前后在同一批测试题上的对比

python learning\11_finetune\02_lora_sft\train.py
