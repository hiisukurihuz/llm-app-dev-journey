# 08 · 多模态

> 状态：⏳ 未开始 ｜ 前置：07_langchain

## 这个模块解决什么问题

让模型"看图、听声、生成图"：图像理解与 OCR、语音识别与合成、文生图，
最后把图片也纳入 RAG 的检索范围（多模态 RAG）。

## 知识点（计划）

- [ ] 多模态大模型：能输入什么、能输出什么
- [ ] 主流模型：GPT-4V、Gemini、Qwen-VL 的能力边界
- [ ] 图像描述与视觉问答（VQA）
- [ ] 文字识别（OCR）与文档截图理解
- [ ] 目标检测与图像分类（能用现成模型，不训练）
- [ ] 语音识别（ASR）与语音合成（TTS）
- [ ] 文生图：提示词写法与限制
- [ ] 多模态 RAG：图片向量化 + 图文混合检索

## 目录（计划）

| 子目录 | 内容 |
|---|---|
| `01_vision_qa/` | 图像描述、VQA、OCR |
| `02_audio_video/` | 语音识别与合成、视频抽帧 |
| `03_image_gen/` | 文生图 |
| `04_multimodal_rag/` | 多模态检索（本模块亮点，可写进简历） |

```powershell
python learning\08_multimodal\01_vision_qa\demo01_image_qa.py
```

## 验收标准（能脱稿讲清）

1. 多模态模型和"OCR + 文本模型"的差别在哪，什么场景必须用前者。
2. 一张图送进模型，token 是怎么算的？为什么图片会显著推高成本。
3. 多模态 RAG 里，图片是怎么变成可检索向量的。
4. 你的场景里，图片解决的是"看清"还是"看懂"的问题。
