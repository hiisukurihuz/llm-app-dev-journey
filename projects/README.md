## 旗舰项目

`00_capstone/` 

知识拆解：

1. **知识库**：设备手册 / 错误码表 / 历史维修工单
2. **检索**：BM25 + 向量混合召回 → Rerank → 答案带出处（可点开到原文段落）
3. **Agent（LangGraph）**：症状采集 → 检索手册 → 生成排查步骤 → 查实时参数 → 输出工单草稿；支持人工介入
4. **工程**：FastAPI + SSE 流式 + Docker Compose + 日志 + Streamlit 前端
5. **评估**：30 条 QA 测试集，记录 Recall@3、答案准确率、幻觉率、P95 延迟、单次成本

交付物：仓库（架构图 + README + 部署说明）、3 篇复盘、5 分钟演示视频、一页纸业务价值。
